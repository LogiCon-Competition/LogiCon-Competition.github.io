Proposed NeurIPS 2026 Competition

LogiCon Competition

Benchmarking LLM-based Contradiction Detection

Contradiction Detection evaluation of LLMs on their ability do detect real-world inter-context conflicts of different semantic/logical bases and explicitness levels. This website is the public hub for the proposal and, if accepted, the competition launch.

Schedule

Draft timeline

Dates will be finalized if the proposal is accepted. All deadlines are Anywhere-on-Earth.

  1. May 2026

    Proposal submission

    Freeze reviewer-facing materials, including this website.

  2. June 2026

    Competition launch

    Release training data, validation data, starter kit, baseline, rules, and registration link.

  3. July-Aug 2026

    Public leaderboard opens

    For validation submissions, scoring sanity checks, and first participant support window.

  4. Set 2026

    Main submission phase

    Competition runs on private test set, with regular FAQ updates and issue triage.

  5. Oct 2026

    Private leaderboard release

    Top submissions verified and Private leaderboard released

  6. Dec 2026

    Competition presentation

    Results and analysis presented at the NeurIPS Competition Track, if accepted.

Participant flow

  1. Register on Codabench.
  2. Download data (and optionally support code) from this website.
  3. Run local validation with the starter kit.
  4. Upload predictions to the Codabench submission phase.
  5. Codabench validates, scores, logs, and updates the leaderboard.

Data release

LogiCon will provide enough public data for participants to develop systems, while keeping the test set and labels protected until the submission period has ceased. Data is exposed through Codabench.

Data package checklist

  • Dataset card, license, citation, and known limitations.
  • Stable release tags and checksums.
  • Example submission and schema validator.
  • Policy for external data, pretrained models, tools, and manual annotation.

FAQ

Frequently asked questions

Will submissions be made on this website?

No. Submissions should be made through the Codabench link above.

How will invalid submissions be handled?

Invalid submissions should receive clear error messages and no leaderboard score unless the platform records them separately as failed attempts.
